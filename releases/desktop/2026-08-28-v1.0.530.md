# DuneCity 1.0.530

- Migrates the simulator-tested QBot production strategy into the public game without shipping the private simulator.
- Prevents strategic production starvation so QBot can progress to Palaces and faction-special units in long custom matches.
- Moves Dune2R remastered art out of the base Windows and Linux packages.
- Adds resumable, SHA-256 verified Dune2R asset downloads from the in-game Dune2R EditoR.
- Preserves downloaded Dune2R asset packs across managed-mod and game upgrades.

The base game still includes Vanilla, DuneCity, Tornie, and the lightweight Dune2R mod shell. Remastered Dune2R art is optional and downloaded per unit or as one queue.
