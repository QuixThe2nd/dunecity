# DuneCity 1.0.526 Desktop

This maintenance release makes DuneCity R/C/I placement feedback match the
gravel-only construction rule introduced in 1.0.525.

## Fixed

- Show invalid red placement tiles wherever a Residential, Commercial, or
  Industrial footprint overlaps sand, spice, dunes, mountains, occupied
  ground, or an existing city zone.
- Use one shared gravel/concrete terrain rule for the placement preview and
  authoritative structure validation.

## Compatibility

- Existing save files remain supported.
- Multiplayer simulation and protocol versions are unchanged.
- Vanilla, DuneCity, Dune2R, and the frozen bundled Tornie version remain
  separately selectable.

## Verification

- Windows x64 Release build
- Complete automated test suite
- Focused city and zone placement tests
