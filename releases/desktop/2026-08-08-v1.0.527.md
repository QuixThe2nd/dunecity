# DuneCity 1.0.527 Desktop

This maintenance release makes bundled mods self-repairing without clearing
the player's entire DuneCity application-data directory, restores MetaServer
HTTPS on Windows 10, and corrects Linux package integration.

## Fixed

- Refresh stale installed copies of the bundled Tornie and Dune2R mods using
  an atomic staged replacement when their packaged payload changes.
- Remove obsolete files from those managed mod copies instead of overlaying a
  new release onto stale assets, preventing malformed SHP and PAK conflicts.
- Preserve save games, settings, logs, editor maps, and independently installed
  user mods during the refresh.
- Fall back to Vanilla if a managed mod cannot be refreshed or its metadata is
  invalid, and roll back a failed in-game mod activation.
- Use the Windows native certificate store when supported and ship a Mozilla CA
  bundle fallback so MetaServer HTTPS works on Windows 10.
- Install Linux packages under `/usr`, publish a discoverable desktop launcher,
  and resolve packaged data relative to the executable for portable builds.

## Compatibility

- Existing save files and user settings remain supported.
- Save-game and multiplayer protocol versions are unchanged.
- Vanilla, DuneCity, Dune2R, Tornie, and user-installed mods remain separately
  selectable.
