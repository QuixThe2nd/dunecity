# DuneCity 1.0.529 Desktop

This release expands vanilla skirmish AI variety and carries the latest
cross-platform input improvements.

## AI

- Let QuantBot maintain deterministic mixed forces with infantry, troopers,
  trikes, raiders, and quads alongside its heavier units.
- Allow vanilla AI bases to construct barracks, WORs, gun turrets, and short
  wall lines when resources and technology permit.
- Vary ordinary structure spacing between compact placement and one-tile lanes
  without introducing multiplayer lockstep randomness.
- Keep DuneCity simulation construction behavior separate from these vanilla
  skirmish changes.

## Input

- Add Auto, Hidden, and Visible cursor policies for Android-class devices.
- Preserve physical mouse cursor visibility through menus, Mentat sequences,
  gameplay, cutscenes, and the map editor.
- Keep touch input cursor-free in Auto mode while detecting real mouse input.

## Compatibility

- Save-game and multiplayer protocol versions are unchanged.
- Vanilla, DuneCity, Dune2R, Tornie, and user-installed mods remain separately
  selectable.

## Downloads

- Windows x64 ZIP and installer are attached to the GitHub release.
- Linux x86_64 AppImage, tarball, and Debian package are attached when the
  Linux build completes successfully.
