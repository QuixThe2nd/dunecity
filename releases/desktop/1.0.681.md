# Dune City 1.0.681

Custom Game opens the original map browser again, for both offline play and
online hosting. Browse a scrolling map list with category tabs, a preview and
map details, then choose Players to configure the game.

- Restore All Maps, SP Maps, SP User Maps, MP Maps and MP User Maps.
- Keep map, mod, game rules, shared-house and offline/online choices in the map
  browser before proceeding to player setup.
- Return with Back or Browse Maps while retaining the selected map and roster.
- Keep the Dune2R and Tornie browser packaging fix from 1.0.679.

Validation: native menu checks cover 640×480, 854×480 and 1280×720, both offline
and online map browsers, map selection and roster preservation. All seven native
test groups pass. Browser build and bundled-mod integrity pass. Interactive browser checks confirm
map categories, preview updates, Online setup, and selection/roster preservation
through Browse Maps and Escape.

Previously disclosed limits remain: different-network two-device multiplayer
and multiplayer save/resume were not verified in this release pass.
