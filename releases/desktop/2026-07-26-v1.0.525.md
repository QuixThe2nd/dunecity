# DuneCity 1.0.525 Desktop

This release restores loaded-save city simulation and adds the first playable
Dune2R enhanced-unit graphics layer.

## Fixed

- Resume city effects, budget scans, demand valves, and zone growth after
  loading a DuneCity campaign save.
- Recover empty-population R/C/I valves that were left in a deadlocked negative
  state by affected saves.
- Build roads at twice the speed of concrete and R/C/I zones at half the Police
  Station build time instead of completing instantly.
- Restrict every DuneCity-only structure to gravel/rock or existing concrete.
  Sand, spice, dunes, and mountains are rejected.

## Dune2R

- Load mod-local animated unit atlases without replacing shared game assets.
- Add idle, movement, and combat animation selection with classic-art fallback.
- Add Action, Tactical, and Strategic presentation zoom levels through the
  Dune2R-only UI control and mouse wheel.
- Include the Ordos Tank proof-of-concept animation package.

## Compatibility

- Existing save files remain supported.
- Multiplayer simulation and protocol versions are unchanged.
- Vanilla, DuneCity, Dune2R, and Tornie remain separately selectable.

## Verification

- Windows x64 Release build
- Complete automated test suite
- Loaded-save R/C/I growth tested manually
- Dune2R Ordos Tank rendering and zoom tested manually
