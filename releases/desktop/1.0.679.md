# Dune City 1.0.679

Campaign, Custom Game and Join Online now have clear entry points. Choose offline
or online within campaign/custom setup, with fewer screens between choosing a
mode and starting a game.

- Restore Dune2R and Tornie in the browser Mods menu and game setup. Include
  their managed files in the browser download and preserve Dune2R across reloads.
- Restore the classic custom-player layout for offline setup and online lobbies,
  with centered player rows, map preview and compact controls for small windows.
- Keep map, mod, game rules and player choices together; retain player choices
  when switching between offline and online.
- Separate campaign/custom filters and invite-code joining from public chat.
- Combine graphics and interface settings. Find Mods and Map Editor in Extras.
- Fix Home keyboard navigation, save the entered hosting name, and explain when
  an online custom game needs an open player slot.
- Improve campaign AI pressure by difficulty, campaign score attribution with AI
  partners, Starport funding and exclusive building selection.

Validation: native and browser builds pass. Native tests and production menu
checks pass at 640×480, 854×480 and 1280×720. Local browser/native campaign and
custom multiplayer were exercised during this work, including a human-hosted
campaign on the preceding 1.0.673 candidate. The 1.0.679 candidate passes all seven native test groups and the new browser
mod packaging tests; the actual browser archive is checked for missing files and
Tornie integrity before publication. Browser upgrade checks confirm both mods
appear in Mods, Custom Game and Campaign, activate and survive reloads. An
offline Tornie custom game reaches gameplay.

Remaining verification: two-device play across different networks and
multiplayer save/resume have not been verified in this release pass.
