# DuneCity 1.0.528 Desktop

This release fixes distorted ADL music on clean Windows systems and expands
the live Dune2R enhanced-unit workflow.

## Fixed

- Render ADL music through a single pitch-stable emulator by default, avoiding
  the detuned stereo effect that distorted music on other computers.
- Apply the same ADL mode to sound effects and report the active audio driver,
  mixer format, buffer size, and ADL mode in the log.
- Retain the legacy harmonic-stereo mode as an opt-in configuration setting.

## Dune2R

- Load mounted damage, aftermath, and dissipation animation states in addition
  to idle, movement, and combat.
- Reload newly mounted unit atlases at runtime from Dune2R EditoR without
  rebuilding the game.
- Package directional damage assets and default-direction fallbacks.
- Include the first mounted Harkonnen Devastator proof-of-concept atlas.

## Compatibility

- Save-game and multiplayer protocol versions are unchanged.
- Vanilla, DuneCity, Dune2R, Tornie, and user-installed mods remain separately
  selectable.
