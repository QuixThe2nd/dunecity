# Dune Legacy Android 0.2.10

Android ARM64 release based on DuneCity 1.0.526.

## Fixed

- Show invalid red placement tiles wherever a Residential, Commercial, or
  Industrial footprint overlaps terrain that cannot accept the structure.
- Keep the DuneCity placement preview synchronized with the authoritative
  gravel/concrete construction rule.

## Included

- Existing selectable Vanilla, DuneCity, Dune2R, and frozen bundled Tornie
  payloads.
- Landscape touch controls, right-click emulation, Android Back/Escape mapping,
  soft keyboard support, and Android-local save paths.

## Compatibility

- ARM64 Android 6.0 or newer
- Existing application data and saves are preserved during upgrade.
- Save format and multiplayer protocol are unchanged from Android 0.2.9.
