# Dune Legacy Android 0.2.13

Android ARM64 release based on the tested DuneCity 1.0.528 payload.

## Included

- Auto, Hidden, and Visible cursor policies for phones, tablets, and Android
  TV devices with physical mice.
- Persistent mouse cursor visibility through Mentat dialogue, menus, gameplay,
  cutscenes, and the map editor.
- Android TV Leanback launcher registration and a television banner so the
  game can appear in compatible home-screen launchers.
- Existing landscape touch controls, right-click emulation, Android
  Back/Escape mapping, soft keyboard support, and Android-local save paths.
- The DuneCity 1.0.528 gameplay payload, including expanded deterministic
  QuantBot unit and base diversity.

## Build

- Require a complete Android NDK 26 or newer; NDK 28.2 is the tested route.
- Pin and checksum the Gradle wrapper used by the APK packager.
- Support warm native-build fingerprints and external build/cache locations.

## Compatibility

- ARM64 Android 6.0 or newer.
- Existing application data and saves are preserved during upgrade.
- Save format and multiplayer protocol are unchanged from Android 0.2.11.
